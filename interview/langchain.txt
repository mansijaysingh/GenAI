❓ Q: What is LangChain?

👉 Answer (perfect):

LangChain is a framework used to build applications powered by LLMs by connecting models with data sources, tools, and workflows.

❓ Q: Why use LangChain?

👉 Answer:

Simplifies LLM app development
Provides modular components
Supports integrations (APIs, DBs)
Enables RAG, agents, memory

❓ Q: What are Chains?

👉 Answer:

Chains are sequences of steps where the output of one step becomes the input of the next.

❓ Q: What are Agents?

👉 Answer (important):

Agents are systems that use LLMs to decide which actions to take and which tools to use dynamically.

❓ Q: What is Memory?

👉 Answer:

Memory allows the system to retain past interactions and maintain conversational context.
