2️⃣ Tools (Hands 🛠️)

👉 jo kaam karte hain:

search

API
database
3️⃣ Agent Executor

👉 actual flow run karta hai

4️⃣ Prompt (Instructions)

👉 batata hai:

kaise decide karna hai
kaunsa tool kab use karna hai

3️⃣ Conversational Agent

👉 memory ke sath

💥 Agent vs Chain

| Chain           | Agent          |
| --------------- | -------------- |

| predefined flow | decision based |
| simple          | intelligent    |


🔥 Agent vs RAG

| RAG           | Agent          |
| ------------- | -------------- |
